DOWNLOADING PROXMOX:
  -  Search Proxmox
  -  Open first webpage or the official proxmox webpage
  -  Go to downloads, scroll down
  -  Download latest iso
DOWNLOADING RUFUS:
  -  Search rufus
  -  Open first webpage or the official rufus webpage
  -  Scroll down
  -  Download latest .exe file
  -  Open when its done
  -  Select Device on which proxmox is to be installed
  -  Then Boot Selection in this case its iso
  -  SELECT drop down button and choose the iso file to be installed
  -  START
  -  Warning Opens up for formatting the removable storage, OK
  -  Wait till its done, PROXMOX Bootable Drive is ready for next steps
